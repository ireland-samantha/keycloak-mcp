# Upstream API data

`data/operations.json`, `data/openapi.json`, and their `-26.3.5` and `-nightly` counterparts are derived from the official Keycloak Admin REST OpenAPI definitions for the [latest release](https://www.keycloak.org/docs-api/latest/rest-api/openapi.json), [26.3.5](https://www.keycloak.org/docs-api/26.3.5/rest-api/openapi.json) and [Keycloak HEAD](https://www.keycloak.org/docs-api/nightly/rest-api/openapi.json). Each catalog's `sourceSha256` records the downloaded source bytes. The generated data is distributed with attribution to the Keycloak project under its Apache License 2.0; see `data/LICENSE-KEYCLOAK.txt`.

The MIT license covers the original code in this repository. No deployment credentials or private extension catalog is part of the package.
